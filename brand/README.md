# 数维弹球 / 双人组织 · 视觉标识

游戏图标和组织图标分开设计，不共享同一套图形语言。

## 游戏图标

`game-icon.svg` 对应《数维弹球》的核心玩法：坐标网格、函数曲线、弹球、检查点、终点。适合 Steam 图标、桌面快捷方式、应用图标和商店封面素材。

| 文件 | 用途 |
| --- | --- |
| `game-icon.svg` | 矢量源文件 |
| `game-icon-1024.png` | 1024px 透明圆角 PNG |
| `overview.png` | 两种图标的并排预览与尺寸检查 |

工程根目录的 `icon.svg` 已同步为游戏图标。

## 组织图标

`organization-icon.svg` 使用两个并肩的人形线稿，直接表达双人协作。没有球、网格、播放键等游戏符号，单色、线性，适合工作室主页、GitHub 组织头像、名片和后续跨领域内容。

| 文件 | 用途 |
| --- | --- |
| `organization-icon.svg` | 黑色线性标，浅色背景 |
| `organization-icon-white.svg` | 反白线性标，深色背景 |
| `organization-icon-badge.svg` | 深色圆角头像徽章 |
| `organization-icon-1024.png` | 黑色透明 PNG |
| `organization-icon-white-1024.png` | 反白透明 PNG |
| `organization-icon-badge-1024.png` | 深色徽章 PNG |

## 使用边界

- 游戏图标只用于《数维弹球》。
- 组织图标用于团队或组织身份，不放进游戏界面充当游戏图标。
- 组织图标建议最小数字尺寸 24px，四周留出至少 1/4 图标宽度的空白。
- 组织图标不要叠加渐变或第二种颜色；需要彩色时可整体换成单一品牌色。
