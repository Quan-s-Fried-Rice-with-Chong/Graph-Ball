# 数维弹球 · B 侧界面原型

在 Godot 中导入本目录的 `project.godot`，按 **F5** 运行。主场景是 `scenes/main.tscn`，启动后先进入主菜单，点击“开始游戏”进入关卡。

界面已按手绘草图与最新反馈改成四排布局：第一排左侧为标识，右侧为当前关卡；第二排左侧为主菜单、关卡选择、教程文档和提示，右侧为公式数量、检查点和用时；第三排左侧为多函数公式列表，右侧为图标工具栏与坐标画布；底部右侧显示操作提示。采用淡蓝灰背景墙、细分隔线与淡色网格。

主菜单背景为颜色较深一档、倾斜滚动的数字墙，文字区域有渐隐处理。关卡选择为独立整页，关卡沿虚线依次排列；未解锁关卡使用较深底色与锁图标，并禁止点击。通关只解锁下一关，已有进度保留。“返回”回到进入选关前的页面。

当前包含四个候选关卡、函数模板选择、参数滑条与数值输入、多函数组合、双滑片定义域、实时曲线、坐标网格、缩放平移、运行/暂停/重试/重置、检查点、障碍、关卡解锁、结算和帮助。窗口基准为 1440 × 900，最小窗口为 1100 × 720。

**当前小球沿曲线匀速移动；重力、真实滚动、反弹和轨道衔接尚未接入。** 四关的参考解已在演示运动中验证，它们是界面联调用的候选关卡，不能据此认定真实物理中也能通关。演示进度独立保存在 `user://b_prototype_progress.cfg`，接入正式逻辑时不要把它当正式通关记录。

## 操作

- 每条函数默认只显示表达式。点击右侧小箭头，展开函数选择、参数与定义域；再次点击即可收起。
- 点击“添加函数”组合多条轨道，最多四条；点击“×”移除，至少保留一条。
- 在展开区选择本关提供的函数，拖滑条或输入数值后按 Enter。
- 定义域用双滑片分别调整上下界，下方两个数值框可微调；定义域外的曲线不参与轨道。
- 多条函数按列表从上到下覆盖 x 范围，重叠时上面的函数优先；相邻定义域应首尾相接。
- 画布上方的三角、暂停、重试与重置均为图标按钮；悬停查看含义和快捷键。
- 蓝线需接到起点；黄色圆环是必经检查点，绿色区域是终点，红色区域是障碍。
- 运行前自动恢复全景；滚轮上下、Shift + 滚轮左右、Ctrl + 滚轮缩放，中键拖动。
- 空格运行/暂停，R 重试，Esc 关闭帮助/选关或暂停。
- 重试保留函数、参数与定义域；重置恢复本关初始模板、参数与定义域。运行和暂停期间锁定全部设置。
- 教程文档和关卡选择会暂停正在运行的小球，返回后点击继续。
- 返回主菜单也会暂停小球，并保留当前公式和参数；点击“继续游戏”返回。
- 坐标网格铺满画布；中间边框标记作图区，曲线只显示在框内。

## 文件分工

| 文件 | 用途 |
|---|---|
| `scenes/main.tscn` / `scripts/ui/main.gd` | 主界面与流程连接 |
| `scenes/components/formula_panel.tscn` | 公式面板，可独立改布局 |
| `scenes/components/graph_canvas.tscn` | 坐标画布，统一处理坐标变换 |
| `scenes/components/result_dialog.tscn` | 成功/失败结算浮层 |
| `scenes/components/main_menu.tscn` | 主菜单及开始/继续游戏入口 |
| `scenes/components/level_select_page.tscn` | 独立整页选关、线性路径与返回入口 |
| `scripts/ui/digit_wall.gd` | 主菜单的斜向滚动数字墙 |
| `scripts/ui/level_route.gd` / `level_card.gd` | 虚线串联关卡与锁定状态显示 |
| `scripts/ui/icon_button.gd` | 原生绘制的工具图标与展开箭头 |
| `scripts/ui/ui_theme.gd` | 统一字体、颜色和控件样式 |
| `scripts/ui/dual_range_slider.gd` | 定义域用的双滑片滑条 |
| `scripts/core/formula_catalog.gd` | 三种模板、参数范围与演示曲线采样 |
| `data/levels.json` | 四关位置、障碍、检查点和初始参数 |
| `scripts/adapters/demo_run_adapter.gd` | 可替换的演示运动层 |
| `docs/AB_INTERFACE.md` | 与 A 对接的数据和事件约定 |
| `tests/smoke_test.gd` | 引擎内自动检查 |

界面使用系统中文字体候选：微软雅黑、Noto Sans CJK 等。当前 Windows 环境已检查中文显示；浏览器和其他系统的字体效果需要另行实测。

## 检查

在项目根目录执行：

```text
Godot --headless --path . --script res://tests/smoke_test.gd -- --prototype-test
```

请确保 `Godot` 命令指向已安装的 Godot 4.7.2 可执行文件。测试使用临时演示存档，结束时删除，不覆盖正常试玩进度。检查包括四关演示解、多函数与定义域、起点不匹配、连续障碍碰撞、检查点、边界、超时、暂停、参数双向同步与锁定、重试/重置、解锁、存档和缩放。报告写入 `artifacts/smoke_report.json`。

引擎版本：Godot 4.7.2 / GDScript / Compatibility。当前验证针对该界面原型；尚未宣称网页导出、网页字体或真实物理验证通过。
